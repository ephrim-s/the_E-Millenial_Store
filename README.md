# The E-Millenial Store

A responsive frontend project showcasing a fictional online gadget store built with HTML, CSS, and JavaScript.

## Overview

The E-Millenial Store is a modern landing page for a hypothetical e-commerce site featuring gadgets like TVs, laptops, smartwatches, and accessories. The project includes a product grid, a cart interface, and a customer checkout form.

## Features

- Responsive landing page layout
- Product grid with “Add to Cart” buttons
- Shopping cart modal with item list and total
- Customer information form inside the cart modal
- Mobile-friendly navigation and layout

## Project Structure

- `index.html` — main site markup
- `styles/main.css` — styling and responsive layout rules
- `scripts/main.js` — cart modal and interaction logic
- `images/` — product, logo, and icon assets

## How to Run

1. Open `index.html` in a web browser.
2. Click the cart icon to open the shopping cart.
3. Use the product buttons to add items to the cart.

## Notes

- This project is a frontend demo and does not include backend functionality.
- The cart currently manages item display and basic total calculation.
